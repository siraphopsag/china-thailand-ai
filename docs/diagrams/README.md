## ตอนทำหน้าแอดมิน

- แปลงเป็นคอมโพเนนต์ในเว็บ: 3 ภาษา (ไทย / จีน / อังกฤษ) และใช้สีตามธีมของเว็บ แทนสีที่ฝังในไฟล์
- ในภาพไม่มีข้อมูลลับ (ไม่มีรหัส คีย์ หรือข้อมูลส่วนบุคคล)
- หน้าหลังบ้านตอนนี้ใช้รหัสที่อยู่ในโค้ดหน้าเว็บ (ใครก็เห็นได้) — ยังไม่ใช่ที่ปลอดภัยจริง จนกว่าจะมีระบบล็อกอินในเฟส 1
